    Live recording requires macOS

    Live recording

    Transcribe your microphone and the call's system audio in real time. Nothing leaves your Mac.

    First launch: macOS will ask for Microphone and Screen Recording permission. After granting Screen Recording you must fully quit (Cmd+Q) and relaunch the app.

    Already enabled but it still doesn't work?

    macOS sometimes desyncs between the Privacy & Security toggle and the actual permission state — this happens when the app's signature changes between builds, or when a previous prompt was denied.

    Reset the saved decisions and grant fresh:

    1. Quit the app fully (Cmd+Q).
    2. Open Terminal and run: 
      tccutil reset ScreenCapture com.transcriber.desktop && tccutil reset Microphone com.transcriber.desktop
    3. Remove the existing Unlimeety entry from Privacy & Security → Screen Recording using the − button.
    4. Relaunch the app and click Allow on the prompts that appear.
